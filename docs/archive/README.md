# Archived release reports

These are the verification and release-validation reports of earlier releases, kept as written; only their relative links changed when they moved here. Each describes the build of its own release: its test counts, checks, screenshots and limitations. None of them describes the current game. Their evidence files stay in [`docs/evidence/`](../evidence/), and the `presentation-verification-v0xx.json` files here belong to the release-validation reports of the same version.

Later releases record their checks in the [changelog](../../CHANGELOG.md) and the [README](../../README.md), and 0.38 in [3D performance](../performance.md) as well. The 0.1.0 [verification record](../verification.md) stays in `docs/`, where the contributor guide cites it as the verification summary.
