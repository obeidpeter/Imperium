# License and asset notices

The graphics library includes **49 locally bundled AI-generated WebP exports**: 22 character portraits, expression variants and seal images; eight narrative scenes; four directional unit atlases; one environment-prop atlas; five action-animation atlases; three ground/scenery atlases; three shared environment surface textures; two versions of the four-material character atlas; and one foliage atlas. The underlying artwork was created for this project using the built-in image generation tool, with existing project-generated images used as continuity references where recorded. Mechanical cropping, resizing and compression produced the exports; the v0.16 character texture is a derivative of the retained v0.15 file, not a separate generation.

The interface also bundles **two mechanical crops of actual browser gameplay** using those project assets and **three code-native PNG app icons**. The icons and related `icon.svg` emblem are original procedural/vector project drawings, not AI-generated artwork. Palette optimization preserves the existing icon design; screenshot cropping does not replace or invent gameplay imagery. See [interface assets](interface-assets.md) for these five files and their processing record.

The optimized images are bundled locally; gameplay has no runtime image-generation or external image-fetching dependency.
