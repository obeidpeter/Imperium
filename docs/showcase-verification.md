### Recorded timing, not a GPU benchmark

The explicit harness sampled 120 actual rendered frames per profile after 18 warm-up frames, at 1440 × 1000 CSS viewport, device ratio 1, and a 1368 × 600 canvas. Each scene contained one legal move followed by idle animation. The browser did other work between profiles; the table is a recorded run, not evidence that High is faster than Balanced. CPU submission time is distinct from GPU time and full-frame latency.

| Profile | Median CPU render ms | p95 CPU render ms | Median rendered-frame interval ms | p95 interval ms |
| --- | ---: | ---: | ---: | ---: |
| Balanced | 14.0 | 32.2 | 38.7 | 79.0 |
| High | 9.0 | 13.2 | 34.4 | 38.7 |
| Performance | 7.5 | 11.5 | 33.4 | 48.4 |

All three measurement runs preserved the committed campaign's serialized SHA-256. No 60 fps, physical-device, GPU-memory or before/after performance claim follows from these figures. Automatic quality reductions now reach the retained 3D stage immediately.
